# My First Full-Stack Web Application 🚀

Welcome to my first full-stack coding project! I built this responsive, interactive web application from the absolute basics on my Chromebook, leveraging a complete frontend and backend architecture.

## 🛠️ Features Included

- **Glassmorphism Design Layout:** A clean UI featuring blurred glass cards, gradient backgrounds, and fluid typography.
- **Scroll-Driven Timeline Animations:** Modern CSS scroll animations that scale components smoothly as you scroll down the page.
- **30-Minute Coding Countdown Clock:** An accurate, interactive countdown timer built with a JavaScript interval engine.
- **Persistent Data Checklist:** A learning goals tracker that syncs checked items dynamically across page refreshes.
- **Daily Motivation API Endpoint:** A background fetch channel that pulls random motivational developer quotes straight from the server.
- **Light & Dark Theme Toggle:** An interactive theme switcher that saves user preferences locally.

## 💻 Tech Stack Under the Hood

- **Frontend:** HTML5, CSS3 (Flexbox, @keyframes, CSS variables), JavaScript (DOM manipulation, Fetch API, LocalStorage).
- **Backend Infrastructure:** Node.js runtime environment, Express.js server routing framework.
- **Version Control:** Git repository snapshots deployed directly to GitHub.

## 🚀 How to Run Locally

1. Clone or download this repository as a ZIP archive.
2. Open your terminal app and navigate into the project folder:
   ```bash
   cd my-first-fullstack-app
   ```
3. Install the server dependencies:
   ```bash
   npm install
   ```
4. Ignite the backend server engine:
   ```bash
   node server.js
   ```
5. Open your web browser and navigate to: `http://localhost:3000`
